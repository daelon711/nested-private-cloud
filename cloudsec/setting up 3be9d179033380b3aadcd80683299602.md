# setting up

1. new vm in vmware
2. add the disk later
3. choose guest OS
    
    ![image.png](setting%20up/image.png)
    
4. disk size 20 GB single file
5. 8RAM 2CPU
    
    ![image.png](setting%20up/image%201.png)
    
6. enable - VT-x/EPT
7. check hyperv status via admin shell
    
    Get-WindowsOptionalFeature -Online -FeatureName HypervisorPlatform
    
8. if vm refuses to boot disable hyperv
    
    Dism.exe /Online /Disable-Feature /FeatureName:HypervisorPlatform
    
9. also disable memory integrity
    
    in core isolation. it is an extra hyper v overwatcher
    
10. if needed reenable hyperv
    
    Dism.exe /Online /Enable-Feature /FeatureName:HypervisorPlatform
    
    this is in case of using WSL2, Docker Desktop in Hyper-V mode, or Windows Sandbox
    
11. also run this script and extract zip: [https://www.microsoft.com/en-us/download/details.aspx?id=53337](https://www.microsoft.com/en-us/download/details.aspx?id=53337)
    
    .\DG_Readiness_Tool_v3.6.ps1 -Disable
    
    then R
    
12. because WSL restarts hyperv on reboot - **Uncheck both Virtual Machine Platform and Windows Subsystem for Linux from control panel** → programs → windows features on or off 
    1. WSL's "Virtual Machine Platform" feature was silently re-enabling Hyper-V/VBS on every reboot
13. shutdown /r /t 0 
14. to enable later - .\DG_Readiness_Tool_v3.6.ps1 -Enable
